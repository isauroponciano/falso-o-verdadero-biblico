# Verdadero o Falso — Oración y Sanidad

Juego interactivo de Verdadero o Falso centrado en temas de oración y sanidad, diseñado para jugar en pareja.
Incluye botón ⏸️ Pausar / ▶️ Reanudar con efecto visual de calma al pausar.

## Cómo usar
1. Descarga y extrae el ZIP.
2. Abre `verdadero-falso-oracion.html` en tu navegador.
3. Introduce los nombres y pulsa Iniciar juego.
4. Usa el botón de pausa para detener el cronómetro. Al reanudar el juego continuará donde se quedó.

## Publicar en GitHub Pages
Sube `verdadero-falso-oracion.html`, la carpeta `sounds/` y `README.md` al root de tu repo. Habilita Pages en Settings → Pages → Branch: main (root).
